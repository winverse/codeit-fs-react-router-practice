# React Router 실습

React Router의 주요 기능을 기존 챌린지 방식으로 연습하는 7개의 독립 프로젝트입니다.

## 시작하기

```bash
git clone https://github.com/winverse/codeit-fs-react-router-practice.git
cd codeit-fs-react-router-practice/01-basic-routing
npm install
npm run dev
```

각 실습은 해당 번호 폴더에서 독립적으로 실행합니다. 먼저 `README.md`의 체크리스트를 따라 직접 구현한 뒤, 막힌 경우에만 수정 파일과 가까운 `answers/`의 같은 파일을 확인합니다. 답안 파일은 앱에서 import하지 않습니다.
